# Flutter Mobile Application

This directory contains the Flutter/Dart client for the CMPE 137 project.

The initial files were integrated from the team's existing Flutter scaffold. Generated platform directories can be created or refreshed with Flutter tooling when development begins.

## Getting Started

From this directory:

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

If platform folders are missing on a local checkout, run:

```bash
flutter create .
```
