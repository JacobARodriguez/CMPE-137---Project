# Core dependencies. Everything here ships prebuilt wheels for Python 3.11-3.14,
# so `pip install -r requirements.txt` never needs a compiler.
#
# Version floors rather than exact pins: exact pins to older releases break on
# newer Pythons, because pip falls back to building from source (pydantic-core
# needs Rust, asyncpg needs a C toolchain). Floors let pip pick a release with a
# wheel for whatever interpreter you are on. If you need reproducible builds,
# generate a lockfile with `pip freeze > requirements.lock` per environment.
